Обновление HTML страницы `/charcoal/` находится в этой ветке. Основная ветка `main` и рабочий сайт не изменены.

## Медиафайлы (требуются для полноценного просмотра)

* `assets/videos/hookah-charcoal-cubes.mp4` — MP4, H.264 / AAC, 720 × 1280, 15,1 с, ~2,38 МБ.
* `assets/images/hookah-charcoal-video-poster.webp` — обложка WebP из исходного ролика, ~26 КБ.

**Внимание:** бинарные медиафайлы подготовлены отдельно, но пока НЕ загружены в эту ветку GitHub. Предпросмотр на GitHub Pages без них не будет воспроизводить видео.

Готовый FTP-архив REG.RU в чате включает HTML и оба медиафайла. Он предназначен для размещения на статическом сайте с текущей структурой папок. Для рабочего домена пути `/op-project-staging/` заменены на `/`. До копирования `charcoal/index.html` на рабочий сайт сравните его с текущим файлом и создайте резервную копию.

## Изменения

Визуальный блок с вертикальным видео располагается после баннера «Производство кальянного угля» и перед формой запроса. Оригинальное видео MOV не изменено. Автовоспроизведение отключено; видео загружается при нажатии пользователем. На мобильных устройствах блок переходит в одну колонку.
