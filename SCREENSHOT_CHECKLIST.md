# Screenshot checklist for final visual polishing

The restoration should remain a copy of the old site. Use screenshots only to resolve layout/visual details that are not reliably recoverable from MHTML/HTTrack.

## Highest priority
1. `/` — full-page desktop screenshot(s), especially:
   - top carousel proportions and spacing
   - industry cards
   - technology icon grid
   - services cards
   - team/about block
   - request form
   - footer
2. `/referencelist/` — expanded/collapsed project cards; MHTML preserved project names but not expanded descriptions.
3. `/insulation/` — full page; source text exists, visual reconstruction is not fully verified.
